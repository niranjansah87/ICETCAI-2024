# ICETCAI-2024 Website

Official website for the **International Conference on Emerging Trends in Cyber Security and Artificial Intelligence (ICETCAI-2024)**  
**Dates:** 29-31 August 2024  
**Location:** Vaddeswaram, Guntur, India

---

## Organized by

**Department of Computer Science and Information Technology**  
Koneru Lakshmaiah Education Foundation (Deemed to be University)  
Vaddeswaram, Guntur, India

---

## Project Structure

- `index.html` – Home page
- `committee.html` – Conference committee details
- `cfp.html` – Call for Papers
- `keynote.html` – Keynote speakers
- `submission.html` – Submission guidelines
- `publication.html` – Publication information
- `registration.html` – Registration details
- `venue.html` – Venue information
- `contact.html` – Contact details
- `css/style.css` – Custom styles
- `script.js` – (Reserved for custom scripts)
- Images and logos in project root

---

## How to Use

1. Clone or download this repository.
2. Open `index.html` in your browser to view the website locally.
3. Edit HTML/CSS files as needed for updates.
